# 🤖 FinTech AI Concierge & Wealth Tracker

Преміальна Full-Stack SaaS платформа для розумного трекінгу капіталу, мультивалютного обліку та ШІ-консалтингу особистих фінансів. Додаток розроблено з урахуванням високих вимог до стабільності бізнес-інваріантів за методологією **TDD (Test-Driven Development)**.

---

## 🌟 Унікальні можливості (Core Features)

*   **⚡ Unified Intelligence Dashboard:** Єдиний реактивний інтерфейс на чистому Tailwind CSS + React Query, де всі фічі взаємодіють без перезавантаження сторінок.
*   **💱 Мультивалютне Ядро:** Повноцінний облік активів у **UAH (₴), USD ($), EUR (€)** з динамічним мапінгом значків та гнучким керуванням картками.
*   **📊 Розумне Бюджетування:** Кастомні місячні ліміти витрат на категорії з автоматичним виявленням оверспендингу та червоною неоновою пульсацією UI.
*   **📉 Динамічна Аналітика:** Автоматичний розрахунок фінансової "ваги" кожної категорії у загальному гаманці користувача за допомогою PostgreSQL агрегацій.
*   **📂 Інтелектуальний Експорт:** Генерація та стрімінг кастомних фінансових звітів у форматі CSV/Excel з урахуванням поточних фільтрів екрану.
*   **🧪 Надійність Елітного Рівня:** Система повністю покрита 12 асинхронними інваріантними тестами на PyTest всередині Docker-контейнерів.

---

## 🛠️ Технологічний Стек (Tech Stack)

*   **Backend:** Python 3.11, FastAPI (Асинхронний REST API), SQLModel (SQLAlchemy + Pydantic v2), Alembic (Міграції бази даних), PyTest + Httpx.
*   **Frontend:** React, TypeScript, Vite, React Query (TanStack), Axios, Tailwind CSS (Glassmorphism & Neon UI).
*   **Database & Infrastructure:** PostgreSQL 15, PgAdmin, Docker & Docker Compose (Повна ізоляція середовищ розробки та тестування за допомогою NullPool).

## 🚀 Швидкий запуск (Quick Start)

Завдяки повній контейнеризації, додаток піднімається однією Full-Stack командою.

1. Переконайтеся, що на вашому Mac запущено **Docker Desktop**.
2. У корені проекту запустіть контейнери:
   ```bash
   docker compose up --build -d
   ```
3. Додаток буде доступний за адресами:
   * **Frontend:** `http://localhost:3000`
   * **FastAPI Backend (Swagger Docs):** `http://localhost:8000/docs`

---

## 🧪 Запуск автоматичних тестів (PyTest)

Для валідації стабільності фінансової логіки та перевірки захисту від овердрафтів і хакерів проженіть тестовий пакет в ізольованій базі даних:
```bash
docker compose exec web env PYTHONPATH=. pytest -v -p no:anyio
```
